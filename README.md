## 功能

### 【天气信息】
* 实时温度、天气状况、最高/最低温度
* 体感温度、风向、湿度、空气质量、紫外线
* 能见度、云量、日出日落

### 【天气预报】
* 未来 48 小时逐时预报
* 温度、湿度可视化图表
* 未来 3 天天气预报
* 降水预报

### 【刷新与缓存】
* 支持下拉刷新和自动刷新
* 可自定义刷新间隔
* 启动时优先显示本地缓存天气
* 后台自动定位并更新天气
* 网络失败时保留已有天气数据

### 【定位与设置】
* 支持自动定位
* 支持手动输入经纬度
* 支持自定义位置名称
* 支持切换自动定位 / 手动位置

### 【其他】
* 使用 HTTPS 请求彩云天气 API
* 原生网络请求，不阻塞天气页面
* 优化 WebView 滚动与页面性能
* API Key 本地配置，不写入源码

## ⚠️ 注意事项

### API Key
* 本项目不提供公共 API Key。
* 请自行前往官网：https://docs.caiyunapp.com/weather-api/index.html 申请彩云天气 API Key，并在应用设置中填写。
* 请不要将包含个人 API Key 的配置文件提交到公开 GitHub 仓库。

### 定位权限
* 使用自动定位功能时，需要允许 Android 应用访问位置信息。
* 如果拒绝定位权限，可以切换到手动位置模式。

### 网络

* 天气数据需要联网获取。
* 如果网络不可用，应用会优先显示之前保存的天气缓存。
